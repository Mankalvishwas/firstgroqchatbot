# LangChain Groq Chatbot

A conversational chatbot built using LangChain and Groq LLM with a Streamlit web interface.

## Tech Stack
- Python
- LangChain
- Groq (LLaMA 3.3 70B)
- Streamlit

## Features
- Ask any question and get instant AI responses
- Built using LangChain chain pipeline
- Free LLM using Groq API

## How to Run
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Add your Groq API key in `.env` file
4. Run: `streamlit run app.py`
